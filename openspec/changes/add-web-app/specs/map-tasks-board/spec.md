# Spec Delta

## Purpose
Вид «Доска задач» (портфель проектов, topology.md №8): второе представление той же модели карты, показывающее статусы ИСПОЛНЕНИЯ задач. Задачи остаются привязаны к гипотезам по горизонтали — суть Карты гипотез не теряется; стрелки задача→гипотеза в этом виде не рисуются.

## ADDED Requirements

### Requirement: Переключение вида
Приложение SHALL предоставлять переключатель вида «Карта | Задачи» в верхней панели: «Карта» — доска с карточками и стрелками; «Задачи» — доска статусов исполнения. Оба вида — представления одной и той же модели; переключение не меняет данные. Вид «Задачи», как и «Карта», рендерится только из валидной модели (при ошибках — полноэкранная страница проблем).

#### Scenario: Переключение туда-обратно
- **WHEN** пользователь переключается на «Задачи» и обратно на «Карта»
- **THEN** оба вида рендерятся из одной и той же модели, данные карты не меняются

### Requirement: Сетка гипотеза × статус
Доска задач SHALL быть сеткой: строки — гипотезы (мини-карточка слева: начало формулировки «Если…», статус проверки оформлением — как на карте, влияние и затраты словами), колонки — статусы исполнения «Не начата | В работе | Готова». Задача попадает в ячейку своей гипотезы и своего статуса (`task.status`, по умолчанию «Не начата»). Стрелок на доске задач нет: привязка задач к гипотезам читается по строкам.

#### Scenario: Задачи по статусам
- **WHEN** у гипотезы две задачи: одна `done`, другая без статуса
- **THEN** первая лежит в колонке «Готова» строки этой гипотезы, вторая — в колонке «Не начата»

#### Scenario: Статус — только исполнение
- **WHEN** задача перешла в «Готова», а её гипотеза ещё не подтверждена
- **THEN** статус проверки гипотезы не меняется автоматически (три независимых аспекта: решение о ресурсах, результат проверки, исполнение)

### Requirement: Карточка задачи на доске
Карточка задачи на доске SHALL показывать описание, исполнителя и срок, направление (`task.group`) меткой-плашкой и активные блокеры («⚠ причина» красной строкой). Цвет карточки — канонический цвет задачи.

#### Scenario: Заблокированная задача
- **WHEN** у задачи есть блокер
- **THEN** на её карточке видна красная строка «⚠ <причина блокера>»

#### Scenario: Задача с направлением
- **WHEN** у задачи задан `group`
- **THEN** на карточке видна серая метка-плашка с названием направления
