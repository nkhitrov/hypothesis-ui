# Spec Delta

## Purpose
Правила целостности модели карты гипотез: любая операция над картой (импорт, применение текста, создание) либо проходит проверку, либо отклоняется с человекочитаемым списком всех найденных проблем сразу.

## ADDED Requirements

### Requirement: Уникальность идентификаторов
Система SHALL отклонять карту, в которой `id` любой сущности повторяется, и указывать оба конфликтующих элемента в сообщении об ошибке.

#### Scenario: Дубликат id
- **WHEN** задача и гипотеза имеют одинаковый `id` `x1`
- **THEN** валидация возвращает ошибку «дубликат id 'x1'» с указанием типов обеих сущностей

### Requirement: Целостность ссылок
Все ссылки между сущностями — `task.hypothesis`, `hypothesis.subject`, `hypothesis.metrics[]`, `blocker.blocks` — MUST указывать на существующие `id`. Каждая битая ссылка отражается отдельной строкой ошибки.

#### Scenario: Задача ссылается на удалённую гипотезу
- **WHEN** задача `t1` ссылается на гипотезу `h9`, которой нет в карте
- **THEN** валидация возвращает ошибку вида «задача 't1': ссылка на несуществующий id 'h9'»

### Requirement: Полнота гипотезы
Гипотеза MUST иметь непустые все четыре части формата «Если—то—потому что—тогда», ссылку на субъекта и хотя бы одну метрику влияния.

#### Scenario: Гипотеза без части «потому что»
- **WHEN** у гипотезы поле `because` пусто
- **THEN** валидация возвращает ошибку с указанием гипотезы и имени пропущенной части

#### Scenario: Гипотеза без метрик
- **WHEN** у гипотезы список `metrics` пуст
- **THEN** валидация возвращает ошибку «не указана ни одна метрика влияния»

### Requirement: Задачи и метрики
Каждая задача MUST быть привязана к гипотезе; каждая метрика MUST иметь значения `current` и `target`.

#### Scenario: Задача без гипотезы
- **WHEN** задача не содержит ссылку `hypothesis`
- **THEN** валидация возвращает ошибку «задача не привязана к гипотезе»

#### Scenario: Метрика без целевого значения
- **WHEN** у метрики поле `target` пусто
- **THEN** валидация возвращает ошибку с указанием метрики и имени поля

### Requirement: Единственный отчёт об ошибках
Валидация SHALL возвращать список всех нарушений сразу, а не прекращаться на первом; пустой список означает валидную карту.

#### Scenario: Карта с несколькими проблемами
- **WHEN** карта содержит дубликат id и две битые ссылки
- **THEN** отчёт содержит три ошибки, сгруппированные по сущностям
