# Spec Delta

## Purpose
Персистентность данных приложения в браузере: карты хранятся локально на устройстве пользователя, без аккаунтов и сервера, и переживают перезагрузку страницы и браузера.

## ADDED Requirements

### Requirement: Локальное хранение карт
Приложение SHALL хранить все карты пользователя в localStorage браузера так, что после закрытия и повторного открытия приложения все карты и их содержимое доступны без входа и сети.

#### Scenario: Перезагрузка страницы
- **WHEN** пользователь изменил карту и перезагрузил страницу
- **THEN** карта отображается с последними сохранёнными изменениями

### Requirement: Автосохранение
Любое применение изменений к карте (через текстовый редактор, импорт или операции над картой) SHALL автоматически сохраняться без отдельного действия «сохранить».

#### Scenario: Правка без явного сохранения
- **WHEN** пользователь применил изменения модели в текстовом редакторе
- **THEN** изменения сразу записаны в хранилище

### Requirement: Управление списком карт
Приложение SHALL предоставлять список карт с операциями: создать пустую, дублировать, переименовать, удалить. Удаление требует подтверждения.

#### Scenario: Дублирование карты
- **WHEN** пользователь дублирует карту «Демо»
- **THEN** в списке появляется копия с новым `id` и названием вида «Демо (копия)», содержимое идентично оригиналу

#### Scenario: Удаление с подтверждением
- **WHEN** пользователь удаляет карту и подтверждает действие
- **THEN** карта исчезает из списка и хранилища; при отмене подтверждения карта остаётся

### Requirement: Первый запуск
При первом запуске (хранилище пусто) приложение SHALL предзагрузить демонстрационную карту с примером стратегии, чтобы новый пользователь сразу видел работающий карточный вид.

#### Scenario: Чистый браузер
- **WHEN** приложение открыто в браузере без сохранённых данных
- **THEN** отображается демо-карта «Смены.Про», доступная для правок и удаления
