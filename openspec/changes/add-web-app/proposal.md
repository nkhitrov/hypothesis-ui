# Proposal

## Why

Карта гипотез (методология картагипотез.рф / Byndyusoft) сейчас существует в этом репозитории как python-пайплайн «YAML → генератор → Mermaid», чей вид отвергнут пользователем, а специализированные сервисы (Гипотезная, Социотех) не имеют импорта и хранят данные в своём облаке. Нужно локальное полноценное веб-приложение с красивым карточным видом, которое можно захостить как статический сервис, с данными в браузере и импортом/экспортом для правок через LLM.

## What Changes

- **BREAKING**: python-пайплайн удаляется (git-история сохраняет baseline); источником правды становится JSON-модель приложения.
- Новое веб-приложение на Vite + React + TypeScript (сборка в статику, рантайм без CDN и сети).
- Карточный вид карты в стиле специализированных сервисов: колоночная раскладка, цветовая семантика типов, статусы гипотез, приоритеты влияния, легенда, зум/пан, hover-подсветка связей.
- Хранение карт в браузере (localStorage): список карт, автосохранение, данные переживают перезагрузку.
- Импорт/экспорт: файлы .json и .yaml (кнопка и drag&drop), буфер обмена; валидация при импорте с человекочитаемыми ошибками.
- Панель «модель как текст» (YAML/JSON) с применением и валидацией — мост для LLM-правок внутри приложения.
- Демо-карта предзагружается при первом запуске.

## Capabilities

### New Capabilities
- `map-model`: машиночитаемая схема данных карты гипотез — сущности (цель, метрика, субъект, гипотеза, задача, блокер), поля, перечисления; единый источник правды для валидации, импорта/экспорта и рендера.
- `map-validation`: правила целостности модели (уникальность id, ссылки, формат гипотезы «Если—то—потому что—тогда», обязательные поля) и человекочитаемые сообщения об ошибках.
- `map-card-view`: визуализация карты карточками: колонки, стрелки по типам связей, стили по статусам и силе влияния, легенда, навигация (зум/пан).
- `map-storage`: персистентность в браузере — список карт с созданием/дублированием/переименованием/удалением, автосохранение изменений.
- `map-io`: импорт и экспорт карты в форматах JSON и YAML, автоопределение формата, валидация при импорте.
- `map-text-editor`: редактирование модели как текста (YAML/JSON) с валидацией, применением и откатом.
- `map-tasks-board`: вид «Доска задач» (портфель проектов, topology.md №8) — статусы исполнения задач в сетке гипотеза × статус, без стрелок.

## Impact

- Код: новый `src/` (React + TS), `package.json`, Vite-конфигурация; удалены `generate.py`, `renderer_cards.py`, `vendor/`, `map.md`, `map.html` (сделано до этого change в baseline-коммитах).
- Зависимости: react, react-dom, js-yaml; dev: vite, @vitejs/plugin-react, typescript.
- Развёртывание: `npm run build` → статика `dist/`, хостится на любом статическом хостинге.
- Схема данных совместима по составу полей с прежним `map.yaml` (переносится в `src/types.ts`).
